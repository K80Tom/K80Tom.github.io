## 首页、作品与关于页分离

首页仅保留视频首屏、导航、介绍与入口，不再渲染项目、经历或页脚。`/projects.html` 为独立「作品」页，以轮播展示四个项目并直接链接原详情地址；`/about.html` 为「关于我」，保留经历、技能、研究摘要、技术分享和联系内容。已有项目详情、论文、荣誉页继续独立。旧首页和原「作品与经历」页的相关 hash 链接会转到关于页对应位置。

轮播使用用户指定的 [Aceternity Carousel](https://ui.aceternity.com/components/carousel)，通过官方 shadcn registry 安装，适配到 `web/src/components/`。保留大卡片、两侧预览与轻微视差，补充循环切换、键盘控制、触屏滑动、项目索引、直接详情链接和无脚本入口。指针移动时才更新视差，暂停 / 减少动态效果时关闭动画。前三张封面为原创 SVG 产品示意；短剧封面编排原站实拍，并分别标记示意和实拍。

## 实现

React + TypeScript + Vite + Tailwind CSS 3，静态预渲染；独立案例地址和可检索的完整 HTML。首页按用户提供的方案改为 CloudFront 视频、中文衬线标题与玻璃按钮；项目卡与详情页继续使用原创 SVG/CSS 场景。按钮基于 shadcn/ui 的 Radix Button，增加 glass 样式。Tailwind 关闭 Preflight，避免改写原有详情样式。

保留 React 的交互能力，同时避免依赖浏览器运行脚本才能看见主要内容。首页使用用户指定的外部循环视频（约 14.14 MB），加载失败显示深蓝背景，内容和入口仍可使用。Google Fonts 加载 Instrument Serif / Inter；中文主标题使用仅包含必要字形的 Noto Serif SC 子集，并提供系统字体回退。外部字体样式异步加载，避免字体服务缓慢时阻塞页面展示与交互启动。视频静音内联播放，遵循减少动态效果偏好及持久化暂停设置，离开视口或切换标签时暂停。无额外视频遮罩、光晕或装饰性渐变。

现有 Pages 主分支曾只保存构建结果。这次使用 `web/` 保存源码，并将生成后的静态页面放到根目录；源码与线上产物随同一提交更新。原 WorkBuddy 目录及其未提交修改均未改动。

## 验证

`npm run build` 包含 TypeScript、静态预渲染、站内路径与关键内容检查。

`scripts/cinematic-check.mjs` 专门检查视频播放、暂停、移动菜单、减少动态效果与网络失败降级。

`scripts/browser-check.mjs` 使用 Playwright 验证桌面、平板、手机的页面与交互。运行时需可用的 Playwright 包；可通过 `NODE_PATH` 指定已有包目录，通过 `CHROME_PATH` 指定测试浏览器，通过 `TEST_URL` 指定站点。截图与结果写入忽略的 `artifacts/`。

发布之前再次构建，将 `dist/` 产物同步到仓库根目录，再正常快进推送到 `main`，不重写远端历史。
