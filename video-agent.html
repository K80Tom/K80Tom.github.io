02 / FROM SKILL TO VIDEO

每个阶段，都留下可以复核的结果。

  1. 01

    编译产品 Pack 与 Recipe

    运营上传录屏、剪辑 Skill 和产品资料，编译结构化规则；独立复核和契约校验后发布。修复只修改审核指出的字段，通过来源摘要、行锁与事务保障并发发布幂等。

  2. 02

    冻结版本，检查环境

    以任务快照绑定执行规则，运行中任务与重试使用冻结版本。近期架构进一步规划冻结 Pack、工具、子 Agent 和校验规则版本，并在启动前完成环境检查。

  3. 03

    观察画面，执行并确认动作

    截图 → 阶段上下文 → 模型决策 → 程序校验 → 真机执行 → 回执复核。记录动作与回执的时间、状态，只有得到确认的动作才进入完成历史。

  4. 04

    保存原片与完成证据

    记录当前阶段、待确认动作、失败位置、剩余预算与原片 Checkpoint。录制结果可独立复用，剪辑阶段失败无需重复整段设备操作。

  5. 05

    生成 EDL，校验后渲染

    剪辑 Skill 约束时序与质量，原片时间戳和动作边界帧帮助生成剪辑决策列表。后端校验 EDL，再由 FFmpeg 执行实际渲染。

  6. 06

    独立复核，有限次修复

    模型质量审核与人工验收共同定位问题，依据具体证据限次重采样、重规划或重渲染；保留原始记录和失败原因，便于追溯。
