五层架构

独立设计并实现的分层 Agent Runtime

L1

模型适配层 · Model Adapter

支持 OpenAI / Anthropic / OpenAI-Compatible 等多模型接入，统一接口抽象

L2

Agent 推理循环层 · ReAct Loop

「思考 → 工具调用 → 观察 → 修复」的自动化编程闭环

L3

工具注册与调用层 · Tool Registry

文件读写 / 代码编辑 / 命令执行 / Glob/Grep 检索 / MCP 工具接入

L4

上下文管理层 · Context Manager

两层渐进式压缩 + 跨会话记忆 + 项目级指令文件加载

L5

权限控制层 · Permission Guard

危险命令识别 / 路径沙箱 / 分级权限确认 / OS 级沙箱兜底

QUICK START

在终端里，开始一次协作。

Python 3.11+。安装 uv，克隆项目并同步依赖，再按仓库说明在本地配置模型。

01 / INSTALL UV
curl -LsSf https://astral.sh/uv/install.sh | sh
02 / SYNC PROJECT
git clone https://github.com/K80Tom/MiniCode.git
cd MiniCode
uv sync
03 / RUN MINICODE
uv run mewcode
uv run mewcode -p "帮我分析这个项目"
uv run mewcode --remote

启动前在 .mewcode/config.yaml 中配置自己的模型服务；Remote 模式默认使用本地地址 http://localhost:18888。安装和配置以 项目 README 为准。
