02 / TASK LIFECYCLE

从理解任务，到验证修改。

  1. 01

    加载项目与任务记忆

    读取项目指令，恢复 JSONL 会话和历史任务；结合记忆提取保留当前目标、已有决定与待处理问题。

  2. 02

    选择并调用工具

    根据模型决策选择代码检索、文件读写、编辑或命令执行；MCP / Skill 扩展工具能力，工具描述按需加载。

  3. 03

    检查权限与文件状态

    识别危险命令与越界路径，要求修改前读取文件，检查文件修改状态，并对不同风险操作使用不同确认等级。

  4. 04

    观察结果并继续修复

    把工具结果和测试反馈送回 ReAct 循环；摘要归档与检查点截断保留关键需求、变更和测试信息，支持长任务继续推进。

持久记录与工作上下文分开

JSONL 会话支持跨次恢复；模型工作上下文经过摘要和截断，缓解随工具结果不断增长的问题。用信息保留测试调整摘要模板，避免丢掉关键约束。

并行工作，需要文件隔离

参与多 Agent 并行执行，以 Git Worktree 隔离目录，验证跨文件修改流程；并行效果在指定重构测试中比较。

LONG-RUNNING TASKS

两层压缩支持 8 小时以上长会话追踪。使用 SWE-bench-Live 验证问题定位、代码修改与测试修复；这些指标对应项目测试条件，不是所有代码任务的统一成绩。

QUICK START

在终端里，开始一次协作。

Python 3.11+。安装 uv，克隆项目并同步依赖，再按仓库说明在本地配置模型。

01 / INSTALL UV
curl -LsSf https://astral.sh/uv/install.sh | sh
02 / SYNC PROJECT
git clone https://github.com/K80Tom/MiniCode.git
cd MiniCode
uv sync
03 / RUN MINICODE
uv run mewcode
uv run mewcode -p "帮我分析这个项目"
uv run mewcode --remote

启动前在 .mewcode/config.yaml 中配置自己的模型服务；Remote 模式默认使用本地地址 http://localhost:18888。安装和配置以 项目 README 为准。
