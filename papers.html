Lightweight Medical Image Segmentation Via Cross-Image Global Structural Filtering Distillation

第一作者西南科技大学IEEE Xplore 收录论文号 11582120
DOI: 10.1109/CSCWD68734.2026.11582120 → 📄 论文全文 PDF →

摘要

深度学习在医学图像分割上精度很高，但模型参数量大，难以部署到边缘设备。知识蒸馏是重要的模型压缩手段，但现有方法在医学图像上存在关键局限：解剖结构类内形态差异大、类间对比度低，且主流技术忽略了全局语义关系、无法抑制特征冗余。本文提出跨图像关系框架 CIGFD（Cross-Image Global Structural Filtering Distillation），通过特征过滤机制在像素与区域双粒度去除冗余、捕捉关键关系线索，实现跨图像精炼全局结构的高效迁移。在 BTCV、Synapse、FLARE 三个公开数据集上一致超越对比方法，为资源受限的边缘设备部署精准高效的医学图像分割模型提供了可行路径。

跨图像结构关系医学图像分割知识蒸馏轻量模型特征过滤

研究动机

现有分割蒸馏方法（SKD、IFVD、CWD 等）主要关注单张图像的内部结构信息，忽略了全局上下文语义；EMKD 虽引入对比学习，但比较范围局限于单张图像内的类内比较。当模型仅依赖单张图像的内部结构信息时，会导致同一器官不同区域间的语义错位，以及难以区分形状或位置相似的器官——在处理不同切片或视角的图像时，模型无法保持对器官结构的一致理解，导致分割结果不一致、精度下降。医学图像高变异性、高噪声的特性（同一器官在不同图像中形态纹理差异显著），迫切需要一种能精确过滤并传递跨图像全局知识的蒸馏方法。

方法框架（三大核心模块）

CIGFD 框架依次实施三种蒸馏策略：① 学习教师的特征紧致图获取关键局部细节；② 通过特征过滤从教师中间层传递关键信息，再从过滤后的特征中提取器官特异向量，经跨图像对比蒸馏构建全局上下文语义；③ 通过 logits 蒸馏对齐输出分布。

模块 A：注意力特征紧致蒸馏（AFCD）

针对师生网络通道特征不匹配导致的无效学习，引入基于通道注意力机制的 AFC 模块，将某层的多通道特征整合为信息丰富的特征紧致图。具体流程：提取师生中间层特征 F_t 和 F_s，将学生特征缩放至与教师相同空间尺寸；对每个通道特征图计算全局平均池化（GAP）得到全局激活响应，经 softmax 归一化为通道权重 λ；最后用权重融合多通道特征为紧致图：

φ(ε) = (1/c) Σ_k λ_k · ‖ε_k‖₂

用 MSE 损失将教师的注意力特征紧致图蒸馏给学生，促使学生生成与教师相似的紧致图，有效蒸馏通道维特征紧致策略。

模块 B：特征过滤模块（FFM）

医学图像分割中冗余信息远多于有效信息，且内脏器官与软组织可能呈现相似特征、缺乏明确的器官判别性。将教师的所有信息传递给学生会导致资源浪费。FFM 先经 AFC 模块映射特征，再用 sigmoid 函数将前景激活目标约束到 [0,1]，最后引入阈值函数过滤不重要的特征（τ=0.5）：

f(x) = x (x ≥ τ), 0 (x < τ)
M_F(e) = f(p_f(M))

过滤后的特征紧致图只保留高激活的前景区域，为后续全局结构构建奠定基础，防止医学图像中普遍存在的噪声信息产生负迁移。

模块 C：高效跨图像对比蒸馏（ECID）

由于图像解剖方向的差异，同类器官也会呈现形状和纹理变化，单张图像的局部结构不足以区分和完整分割器官。ECID 将过滤后的师生特征与对应器官掩码相乘，提取器官区域掩码向量：

R_c(M_F) = Σ_h Σ_w (M_F · m̂_c)_{h,w} / Σ_h Σ_w m̂_c

将 B×C 维度展平实现图像特征展平，计算学生与教师类别特征的相似度矩阵，用 InfoNCE 损失进行对比学习——对角线元素（同器官）相似度被放大，非对角线（不同器官）被抑制，从而增强学生网络的器官判别性和分割完整性。

实验设置

数据集：BTCV（13 器官）、Synapse（8 器官）、FLARE（4 器官）；教师网络：RA-UNet / ResNet34-UNet；学生网络：ENet / ResNet-18；优化器 Adam（初始学习率 1×10⁻³，余弦退火至 1×10⁻⁶），batch size=4，训练 50 epochs；数据增强：随机缩放、旋转；硬件：NVIDIA RTX 4090 (24GB)。评估指标：Dice 与 mIoU（所有类别取平均）。对比方法：CWD、EMKD、CIRKD、BPKD。总损失函数：

L_total = L_SEG + α₁·L_AFCD + α₂·L_ECID + β·L_LD

超参数 α₁=0.5，α₂=0.1，β=0.2，特征过滤阈值 τ=0.5。

超参数敏感性分析

α₁、α₂、β 对模型性能影响极小，方法对这些参数鲁棒；特征过滤阈值 τ 影响显著——τ 过高只保留高显著性特征响应，可能丢失关键语义信息；τ 过低保留大量非显著特征，引入冗余噪声。实验建议 τ 取值范围 [0.4, 0.6] 以平衡细节保留与噪声抑制。

定性分析

可视化结果显示，CIGFD 的分割结果更完整、细节更精细（边界更锐利），更接近 ground truth——证明该蒸馏方法能让学生网络有效获取结构知识与细节知识，实现更优的分割性能。

摘要

深度学习模型在医学图像分割上精度很高，但参数量大、计算昂贵，难以临床部署。知识蒸馏是有效的模型压缩手段，但现有方法面临两大挑战：① 解剖结构类内形态差异大、类间对比度低；② 器官尺寸差异悬殊导致严重类别不平衡。本文提出 CIRGBD 蒸馏框架，包含两个互补模块：跨图像区域对比蒸馏（CIRD）——通过最大化批内区域类内相似度、最小化类间相似度来增强特征判别性；全局边界蒸馏（GBD）——提取全局边界掩码并对所有器官边界统一赋权，有效缓解大器官主导问题。在 BTCV、Synapse、FLARE 三个基准数据集上，CIRGBD 一致提升轻量学生模型性能，mIoU 最高提升 4.43%。

医学图像分割知识蒸馏类别区分边界对齐

研究动机

现有分割蒸馏方法（SKD、IFVD、CWD 等）主要关注空间信息对齐，忽略了类内/类间信息与边界对齐；EMKD、CIRKD 虽引入对比学习，但仅局限于单张图像内的类内比较，且未显式建模边界；BPKD 按类别独立对齐边界，在 CityScapes 等类别尺寸差异小的数据集上有效，但在医学图像中，器官尺寸差异悬殊导致大器官的边界像素主导蒸馏过程，小器官边界模糊。医学图像分割面临两大特有挑战：

挑战 ①：同一器官因成像角度、尺度不同呈现显著形态与纹理差异，仅靠空间信息不足以准确区分类别
挑战 ②：器官尺寸差异悬殊，大器官边界像素在类别边界对齐中占主导，导致小器官边界模糊

方法框架

整体框架由 CIRD 与 GBD 两个模块组成：CIRD 从低层与高层特征层提取区域信息（低层保留器官边界与纹理等空间细节，高层编码抽象语义与结构信息），GBD 在预测层执行全局边界对齐，最终与基线交叉熵分割蒸馏损失组合。

3.1 跨图像区域对比蒸馏（CIRD）

CIRD 建模跨图像的全局结构关系，而非细粒度空间对齐。以 BTCV 数据集（batch size=8）为例：从教师模型预测图提取二值化类别掩码，调整至特征图尺寸后与所有通道相乘得到类别加权特征，对类别区域做平均池化得到各类别的区域特征向量：

R_c = Σ_h Σ_w (x · m̂_c)_{h,w} / Σ_h Σ_w m̂_c

其中 x ∈ R^{B×C_f×H×W} 为特征图，m̂_c 为类别 c 的掩码，R_c ∈ R^{B×C_f} 为批内类别特征（第 i 行对应第 i 张图像）。将各类别区域特征沿类别维度堆叠为 F = [R_1, ..., R_{C_c}]，学生与教师的跨图像区域特征经 L2 归一化后送入 InfoNCE 模块进行对比学习：

S = s_vectors · t_vectors^T / τ
L_CIRD = (1/B·C) Σ_i [ -log( e^{S_{i,i}/τ} / Σ_j e^{S_{i,j}/τ} ) ]

对角线元素 S_{i,i} 表示同类师生特征相似度，经 softmax 放大；非对角线元素被抑制，从而增强类间判别性。温度参数 τ = 0.1。

3.2 全局边界蒸馏（GBD）

传统 BPKD 按类别独立对齐边界，在器官尺寸差异大的医学场景中被大器官主导。GBD 改为：对师生模型最终预测层沿通道维做 softmax 得到类别预测分数图；用 Sobel 算子从教师预测图提取全局边界掩码 mask_global（阈值 k=0.5 控制边界检测灵敏度）；将各类别预测通道与全局边界掩码逐元素相乘，用 KL 散度对齐师生的边界建模能力：

p = Σ_h Σ_w (x · mask_global)_{h,w}, kl_div = Σ_i (p_i^s ∥ p_i^t)
L_global = kl_div / Σ_h Σ_w mask_global

虽然全局边界掩码在空间上不区分类别，但类别信息通过通道维预测分数隐式保留：softmax 归一化后每个类别通道主要在其对应边界区域呈高置信度，因此各通道 KL 散度的主导贡献仍来自其自身类别边界。全局边界形式为所有边界像素赋予同等重要性，缓解器官尺寸不平衡，同时保持类别判别性。

3.3 总体损失

L_total = L_seg + α₁·L_circ_low + α₂·L_circ_high + β·L_global

其中 L_seg 为交叉熵分割损失；超参数 α₁=0.1，α₂=0.5，β=0.1；τ=0.1，k=0.5。

实验设置

数据集：BTCV（13 类）、Synapse（8 类）、FLARE（4 类）；数据增强：随机翻转、旋转、裁剪；优化器 Adam（β₁=0.9, β₂=0.999），batch size=8，初始学习率 0.001，训练 80 epochs；硬件：4 × RTX 4090 (24GB)。评估指标：Dice 系数与 mIoU（所有类别取平均）。教师模型：RA-UNET / RESNET34-UNET；学生模型：ENET / RESNET18 / RESNET18-UNET。对比方法：EMKD、CIRKD、CWD、BPKD（均重新实现以保证公平）。

计算效率

CIRGBD 在提升精度的同时完全保留学生模型的轻量特性：参数量与 FLOPS 与基线方法及原始学生模型完全一致，零额外计算开销；多数配置下推理速度反而更快（如 ENET 在 BTCV 上 FPS 57.46，高于 EMKD 的 57.12）。这得益于 CIRD 与 GBD 仅对现有特征图与预测结果做掩码加权、平均池化、Sobel 边缘提取等简单操作，不引入额外卷积层或网络分支，高度契合临床部署需求。

定性分析

可视化结果显示，CIRGBD 生成的器官分割结果更完整、边界更平滑：对 BTCV 中胆囊、胰腺等小型解剖结构能准确捕捉细粒度特征（基线方法难以做到）；CIRD 有效纠正类别区分度低的误分割区域，GBD 使模糊不均的边界变得精确清晰。
